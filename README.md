# Bedroom Labs Landing Page

A simple static foundation page for Bedroom Labs.

## Open locally

Open `index.html` directly in a browser.

No build step or local server is required. The page uses repo-local asset paths:

- `graphics/BL_banner.png`
- `graphics/BL_logo.png`
- `graphics/BL_logo_main.png`

If you prefer to use a local server, start it from this `Webpage` folder and open `index.html`.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `README.md` - local usage notes
